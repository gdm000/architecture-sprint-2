
## Как запустить

Запускаем mongodb и приложение

```shell
docker compose up -d
```

Настраиваем и заполняем mongodb данными

```shell
./scripts/mongo-init.sh
```

Затем выполняем
```shell
./scripts/mongo-post-init.sh
```

В конце будет выведено общее количество документов и базе, а так же в каждом из шардов.
Далее будет выведен информация о репликах для каждого из шардов.

Для вывода информации о кластере через приложение:
curl http://127.0.0.1:8080/
